Hadye's Cars
A personal portfolio and car showcase website built in vanilla HTML and CSS — no frameworks, no libraries. The site combines a passion for cars with frontend development skills, featuring a top 10 car ranking, performance specifications, and a portfolio of other projects.
What It Does

Home page — hero banner, welcome section, and a personal story about the inspiration behind the site
Top 10 Ranking — curated list of favourite cars with performance specs and imagery
About page — personal background and developer context
Responsive navigation with a hamburger menu for mobile
Background video section with autoplay, muted loop

Tech Stack

Vanilla HTML5
Vanilla CSS3 (no frameworks)
Google Fonts (Bebas Neue, Roboto Condensed, Open Sans, Libre Baskerville)
